
# Văn Phòng Phẩm Website

Dự án **quản lý cửa hàng văn phòng phẩm** với mục tiêu _tổ chức dữ liệu và theo dõi đơn bán_.

## Giới thiệu

Dự án thực hành kỹ năng quản lý file, xử lý log và Excel.

## Cấu trúc thư mục

| Thư Mục | Nội Dung |
|:---:|:---:|
| docs | Tài liệu |
| media | Hình ảnh |
| data | Dữ liệu đơn bán |
